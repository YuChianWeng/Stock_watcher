> 依 `DESIGN-BRIEF.md` 製作（F0 設計階段）。所有商品、價格與損益都是**虛構範例**，不是真實行情。

## 1. 風格

**深色量化儀表板**：近黑的深海軍藍底（`#05070D`）、24px 髮絲線格點、左上青色與右上紫色兩團極淡光暈；重點卡片有漸層描邊與角落刻度；數字一律等寬。目標是「像在看一台儀器」：安靜、精準，只有資料會發光。

- 主色 **青 `#3EE6FF`**（即時、選取、主要動作）＋副色 **紫 `#8B7CFF`**（我的部位、成本線、買點）。主要按鈕用青→紫漸層。
- 漲跌是**語意變數** `--up`／`--dn`：預設紅漲（`#FF4D6A`）綠跌（`#14D98A`），`data-colors="intl"` 時交換。
- **錯誤與中斷用橘色 `--cut`**，刻意不用紅色，避免和「上漲」混淆；稍舊／警告用琥珀 `--wa`。
- 淺色主題是冷白「實驗室」：同一套語意，顏色壓深以達到 WCAG AA 對比。

## 2. 設計系統

### 2.1 色彩（深色）

| Token | 值 | 用途 |
|---|---|---|
| `--bg` / `--bg2` | `#05070D` / `#080C18` | App 底／側欄與分頁列 |
| `--s1` `--s2` `--s3` | `#0A0F1E` `#0F1629` `#162038` | 卡片／區塊、輸入框／hover、選取 |
| `--ln` `--ln2` | 藍 12%／24% | 髮絲線／框線 |
| `--tx` `--mu` `--mu2` | `#E7EEFF` `#8C99BA` `#5A6687` | 主要／次要／第三層（也用於過期價格） |
| `--ac` `--ac2` | `#3EE6FF` `#8B7CFF` | 品牌青、紫 |
| `--rise` `--fall` `--flat` | `#FF4D6A` `#14D98A` `#A3AECB` | 紅、綠、平盤 |
| `--wa` `--cut` | `#FFB547` `#FF8A3D` | 稍舊／警告、中斷／錯誤 |
| 圖表 | `--ch-line` 青、`--ch-prev` 灰點線、`--ch-cost` 紫、`--ch-alert` 琥珀虛線；MA5 黃 `#FFD166`、MA10 粉 `#FF8FD8`、MA20 青、MA60 紫 `#A78BFA` |

### 2.2 字型與數字

| 角色 | 字型 | 規格 |
|---|---|---|
| 中文內文 | Noto Sans TC | 15／1.5；次要 13、第三層 12 |
| 標題 | Manrope 700 | 頁面 24、卡片 16 |
| **數字** | **JetBrains Mono**（tabular、slashed-zero） | 個股現價 44、總市值 28–30、指數卡 22–28、列表 16、漲跌 13、代號 12 |
| 區塊標籤 | JetBrains Mono 600 11 大寫 0.14em | `EYEBROW` |

輸入框一律 ≥ 16px；點擊目標 ≥ 44pt。

### 2.3 間距、圓角、圖示

- 間距 4／8／12／16／24／32；卡片內距 16、手機邊距 16（含安全區域）。
- 圓角 8（標籤）／12（按鈕、輸入）／18（卡片）／22（底部面板），與記帳 App 相同。
- 圖示：24 格、1.7px 線、圓頭圓角（與記帳 App 相同的線條風格）。

## 3. 導覽與版面

| 寬度 | 結構 |
|---|---|

| ≥ 960px（iPad 橫式、桌面） | 左側 76px 圖示列（總覽、自選、警報、設定、搜尋，底部是通知鈴鐺）；滑過顯示名稱 |
| 總覽 ≥ 960 | 左欄：大盤兩卡、持倉摘要、持倉表格；右欄 380–420px：自選 |
| 個股頁 960–1179 | 兩欄：圖表｜部位、報價、警報 |
| 個股頁 ≥ 1180 | 三欄：清單 300｜圖表｜部位、報價、警報 340（左右欄各自捲動、sticky） |

## 4. 價格狀態（最重要）

| 狀態 | 列表 | 標題區 | 圖表 |
|---|---|---|---|
| 即時 `live` | 不標示 | 青色脈動點「即時」＋時間 | 最後點實心標籤 |
| 稍舊 `delayed` | 琥珀標籤「稍舊 HH:mm:ss」 | 同左 | 最後點標籤琥珀框 |
| 過期 `stale` | **價格降為 --mu2、虛線底線、走勢圖轉灰**、虛線框「過期 HH:mm」 | 同左＋提示條 | 標籤變灰，不延伸到現在 |
| 收盤 `closed` | 不標示（總覽頂部顯示收盤） | 「收盤 MM/DD」 | 完整收盤線 |
| 中斷 `disconnected` | 同過期＋橘色「來源中斷」 | 橘色提示條「顯示 HH:mm 的最後資料，警報暫停判斷」＋重試 | 線停在中斷時刻 |
| 無資料 `no_data` | 價格「—」 | 「無資料」＋原因 | 空圖「尚無資料」 |

特殊價格：漲停／跌停用**實心**紅／綠「漲停」「跌停」標籤（取代百分比膠囊）；平盤用「—」與中性色；暫停交易用琥珀框「暫停交易」。

## 5. 畫面

完整畫面在設計板。每一頁都有 iPhone、iPad 直式、iPad 橫式、桌面四種尺寸（iPad 橫式＝桌面版面）。

1. **總覽**：市場狀態列（盤前／盤中／收盤撮合／盤後／休市＋下次開市）→ 加權、櫃買指數卡（迷你分時）→ 持倉摘要（總市值、今日損益、未實現損益；毛額／扣稅費切換；過期與無報價檔數提示）→ 持倉清單（可排序）→ 自選（多清單分段切換）。下拉更新。
2. **個股／指數頁**：標題區（名稱、代號、44px 現價、漲跌、%、資料狀態、漲跌停價）→ 週期分段（分時／日／週／月）＋疊加層與全螢幕按鈕 → 圖表 → 我的部位 → 報價資訊 → 這檔的警報。指數頁沒有部位，量能用成交金額。
3. **自選管理**：清單分段＋編輯（新增／命名／刪除，預設清單不可刪）、搜尋新增（顯示「已在清單」「已持有」）、拖曳把手排序、左滑刪除。
4. **警報**：依狀態分組（啟用中／已暫停／已觸發／錯誤／已到期），每則顯示條件白話、目前值與「距離 ±x%」、頻率、管道、最後觸發；桌面右側是通知紀錄。
5. **新增／編輯警報**：手機全頁、桌面右側面板。商品 → 6 種規則卡（白話＋例子）→ 條件（≥／≤ 分段＋步進器，顯示現價與距離、可設範圍）→ 頻率（每次時顯示冷卻）→ 管道（推播、Telegram 複選）→ 備註、到期。即時提示：已滿足條件、沒有可用推播裝置。
6. **通知紀錄**：時間倒序、未讀青點、觸發價格、各管道投遞結果（成功／失敗／略過）、延後補發、全部標為已讀。
7. **設定**：通知（權限狀態與裝置）、漲跌顏色、主題、圖表預設、損益基準、資料來源狀態、關於與「如何加入主畫面」。

## 6. 圖表規格

見設計板「圖表規格」。重點：

- 分時：價格線＋光暈、漸層面積（資料不完整時不畫面積）、昨收點線、漲跌停標示、每分鐘量柱；X 軸固定為 session_start–session_end。
- K 線：上漲空心、下跌實心；最後一根 partial 虛線框；MA5／10／20／60；量能副圖；KD／MACD／RSI 副圖同步游標。
- 疊加：成本線（紫實線）、警報線（琥珀虛線＋🔔價位）、B／S 點；可個別開關。
- 互動：長按 350ms 十字游標、拖曳平移、雙指縮放、雙擊還原、往左到底載入更早資料；游標浮層附「在此價位設警報」。
- 缺資料：「分時線自 HH:mm 起」、缺口斷線不補線、「資料自 YYYY/MM/DD 起」。
- `touch-action: pan-y`：水平手勢屬於圖表；圖表內拖曳不觸發下拉更新。

## 7. 通知

- 權限 6 種狀態各一張卡：不支援、尚未加入主畫面（三步驟圖解）、尚未允許（使用者按「開啟通知」才跳系統視窗）、已啟用（裝置清單＋測試通知）、訂閱失效（重新啟用）、已拒絕（引導到 設定 → 通知 → 看盤）。
- 鎖屏文案：標題 `{名稱} {代號}｜{規則}`，內文 `現價 {價格}（{±%}）· {HH:mm} · {資料狀態／延後補發}`。價格、跌幅、爆量、均線、漲跌停、延後補發、測試通知範例見設計板。
- 點擊通知 → 個股頁，頂部提示「由警報開啟」並高亮警報線。App 圖示角標＝未讀數。

## 8. 主畫面 App

- App 圖示：深色圓角方形，K 棒＋上升的青紫光線，終點是發光的「即時」點（`icon.svg`，輸出 192／512／maskable／apple-touch）。
- 啟動畫面：深色底＋光暈＋圖示＋「看盤」漸層字。
- 提示條：離線（橘）、有新版本（青）、登入過期（琥珀，保留表單）、來源中斷（橘＋重試）。
- 安全區域：頂部列 `padding-top: 10px + inset-top`，分頁列 `padding-bottom: 6px + inset-bottom`。

## 9. 與記帳 App 的一致與不同

| | 一致 | 刻意不同 |
|---|---|---|
| Tokens | 同樣的變數名稱、圓角 8／12／18、44pt、安全區域變數 | 底色由暖炭灰改為偏藍近黑；主色改為青＋紫漸層光 |
| 導覽 | 手機底部分頁列；≥960 左側圖示列 | 圖示列更窄（76px），寬度留給圖表；個股頁三欄 |
| 卡片 | 圓角卡片、髮絲線、16px 標題 | 重點卡片漸層描邊與角落刻度；背景 24px 格點 |
| 字型 | Noto Sans TC＋Manrope | 數字用等寬 JetBrains Mono |
| 顏色語意 | 金額不只靠顏色 | 紅漲綠跌可切換；錯誤用橘色 |
| 主題 | 深色為主，系統／深色／淺色 | 淺色為冷白而非咖啡紙色 |
| 圖示 | 深底圓角方形、1.7px 線條 | 獨立圖示（K 棒＋光線） |
